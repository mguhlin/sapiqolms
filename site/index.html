Your server. Your learning.

A small stack.
A clear starting point.

PHP and PDO power the application. Start with SQLite, or configure MySQL/MariaDB for your installation. No Composer or npm is required to run the LMS.

Download the source ZIP ↓
● ● ●Linux / macOS quick start
# Download the project
git clone https://github.com/mguhlin/sapiqolms.git
cd sapiqolms

# Create your administrator account
bash installer/install.sh

# Open http://localhost:8000
bash installer/serve.sh

PHP 8.1+ and the required extensions. The installer checks your environment and prompts for credentials.

About this website

This is the project introduction on GitHub Pages. The working LMS runs on your PHP server or in Docker. Pages does not host learner accounts or execute PHP.
