# Redeeming an enrollment code

**Audience:** learner (and prospective participant)
**Where:** **Redeem a code** in the top navigation, the **🎟️ Redeem a code** button
on your dashboard, the **Redeem a code** link on the sign-in page, or a link your
organization sent you (`/redeem?code=…`). You can also type a code in the
**Enrollment code** field when you create your account.

## What it is
An **enrollment code** is a short code (for example `ABCD-EF23-GH45`) that instantly
enrolls you in one or more courses. Your organization or course provider hands these
out — a single code can unlock a whole series of courses, which is how group and
cohort subscriptions work. You never have to hunt through the catalog: redeem the
code and the course(s) appear on your dashboard.

## How to use it

### If you already have an account
1. Sign in.
2. Choose **Redeem a code** in the top navigation, or the **🎟️ Redeem a code**
   button on your dashboard.
3. Type your code and choose **Redeem**.
4. A confirmation lists the course(s) you now have access to, and they appear under
   **Your courses** on the dashboard. Choose **Start** to begin.

### If you are brand new (redeem first, then sign up)
1. On the sign-in page choose **Redeem a code** (under "Have an enrollment code?"),
   or open the link your organization sent you.
2. Enter your code and choose **Continue**. Sapiqo checks the code right away, so
   you find out immediately if it is valid.
3. Create your account (or sign in if you already have one). Your code is applied
   **automatically** the moment your account is ready — no need to re-enter it.
4. You land on your dashboard already enrolled, with a welcome message listing your
   course(s).

You can also just paste the code into the **Enrollment code (optional)** field on
the registration form — same result.

## Options & behavior
- **One or many courses.** A single code may grant several courses at once (a
  series or bundle). All of them are added together.
- **Enter it once.** After you redeem a code it is tied to your account. Re-entering
  the same code simply re-confirms your access — it never double-counts against the
  code's available seats.
- **Instant feedback.** If a code is mistyped, expired, deactivated, or has run out
  of seats, you are told exactly why so you can ask your provider for a new one.
- **Case and spaces don't matter.** Codes are matched in upper case with spaces
  removed, so `welcome-2026` and `WELCOME-2026` are the same code.
- **Keeps your access.** Even if the provider later deletes or deactivates the code,
  courses you already unlocked with it stay on your dashboard.

## How it works
Redeeming enrolls you in every course attached to the code (the same enrollment used
everywhere else in Sapiqo, so progress, badges, and certificates all behave
normally). When you start from a link or the sign-in page while logged out, the code
is validated and held for you, then applied automatically right after you sign in or
finish creating your account.

## Tips & gotchas
- **Redeem before you browse.** If you were given a code, redeem it first — it is
  faster than finding each course in the catalog, and it is how bundles arrive.
- **Expired or full?** Codes can have an expiry date and a limited number of seats.
  If yours no longer works, ask whoever gave it to you for a fresh code.
- **A code is not a password.** It only enrolls you in courses; it never signs you in
  by itself. You still create and use your own account.
- **Lost the link?** Any code works from the **Redeem a code** page — you don't need
  the original link, just the code itself.
