# Welcome

## 0.1 Introduction
This whole course is a single Markdown file. Editing it and re-running the build
regenerates the course, which the LMS picks up automatically.

You will learn to:

- Structure a course with modules and lessons
- Add **images**, *videos*, and resources
- Publish by dropping the folder into `courses/`

## 0.2 How It Works
Headings drive the structure:

1. `# ` starts a module
2. `## ` starts a lesson
3. `### ` is a heading inside a lesson

> Tip: keep lessons short and focused — one idea each.

# Module 1: Authoring Basics

## 1.1 Text and Media
Write in plain Markdown. You can embed a Vimeo video with one line:

@video https://vimeo.com/741221819

And link out to references:

@resource [Your Organization](https://example.org) Your Organization
@resource [Markdown Guide](https://www.markdownguide.org) A friendly Markdown reference

### Formatting
You get **bold**, *italic*, `inline code`, lists, and blockquotes — enough for
clear, readable lessons.

## 1.2 Practice On Your Own
Copy `template.md`, change the front matter, write two lessons, and build it.
